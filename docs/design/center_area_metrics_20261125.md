# 中心距离与面积精确率 / 召回率（2026-11-25）

只用 11-19 已有的模型回复（`benchmark/exports/eval_v2_20261119/runs/*.raw.jsonl`），没有重跑任何模型，没有花钱。题目是 260 题集（难度三档 133 / 51 / 76），金标准、线缓冲规则和现有 `score_polygon` 评分完全一致。

## 结论

1. **中心位置：Sol 基本都找对了地方，Qwen 差一个量级，Gemma 接近乱点。** 预测几何中心到金标准几何中心的距离（中位数，占图像对角线）：Sol 0.67% [0.53, 0.82]（地面约 74 m），260 题中 94.6% 在对角线 5% 以内；Qwen 3.34% [2.63, 3.89]（约 385 m），74 题无预测（73 题答 none、1 题无法解析），5% 命中 46.2%；Gemma 严格 / 宽松 14.2% / 17.1%，5% 命中只有 10.8% / 11.5%。对 Sol 来说 5% 这个阈值已接近天花板，它的失分主要不在"找错地方"，而在区域画得准不准。
2. **面积：Sol 的框总体不偏大，但套不规则多边形时必然多画。** Sol 面状题精确率 0.633 / 召回率 0.593，面积比 P/G 中位数 1.02；线状题正确度 0.711 / 完整度 0.710，面积比 1.00。按金标准形状拆开：矩形题（154）面积比 0.94、召回 0.548 < 精确 0.646，说明失分主要是框偏小或偏移，不是画大；不规则多边形题（31）面积比 1.67、召回 0.816、精确 0.572，是用矩形框住不规则区域带来的。Qwen 面状面积比 1.31（59% 的题画得比金标准大），精确率 0.369；Gemma 面积比 1.67–1.91，又大又偏。
3. **难度三档：Qwen 在中心距离、5% 命中、召回率上都随档位单调变差，Sol 只在面状题召回率上有下降趋势。** Qwen 5% 命中 57.1% → 37.3% → 32.9%（KW p = 0.001，JT p = 0.0002），有预测题的中心距离中位数 2.6% → 2.5% → 5.7%（KW p = 0.002），召回率 0.326 → 0.200 → 0.212（JT p = 0.002）；只算面状题更明显（5% 命中 62.8% → 35.0% → 27.5%），线状题三档没有差别。Sol 中心距离三档无差别（0.70% / 0.49% / 0.67%，KW p = 0.63），精确率也不降（0.632 / 0.671 / 0.687）；唯一的趋势是面状题召回率 0.649 → 0.525 → 0.543（JT p = 0.015，KW p = 0.058）。也就是说难题上 Sol 位置照样找得到，但框住的范围覆盖不全，这和 `difficulty_cue_results_20261125.md` 里"只在面状题 hit@0.5 上下降"一致。Gemma 各档都很差，没有可解释的趋势。
4. **分组：跨尺度比较要用对角线比例，不要用米。** Sol 地面距离中位数局地 46 m、区域 395 m、国家 4.3 km，相差两个量级，但占对角线比例都在 0.36–0.71%。四类里 Sol 武装冲突中心距离最大（1.00%，其他三类 0.46–0.60%），召回 / 精确率各类接近；Qwen 灾害类最弱（5% 命中 26.3%，57 题里 24 题无预测），公共卫生类最好（57.1%，精确率 0.547）。
5. **比例尺缺失 19 题**（4 张示意图：`ds_chicago_full / ds_chicago_south / ds_chicago_west / sp_paris1900`），这些题只报对角线比例，不进米数统计。米数有 116 题来自地图范围估计（high 39、medium 77），只能当量级看。

## 定义

- **几何中心**：框 = 框中心；多边形 = 面积质心（鞋带公式）；折线 = 各段中点按段长加权的质心。金标准和预测用同一套定义。注意现有评分里的 `centroid_dist_norm` 用的是顶点平均，框的结果相同，多边形和折线会略有差别。预测中心不裁剪到图内。
- **中心距离**：像素距离 ÷ 图像对角线（%），以及 × 米/像素（地面米）。无预测的题单独计数，不进距离统计；"≤ 对角线 5%"的比例分母是全部题，无预测算未命中。
- **区域**：G = 金标准掩膜，P = 预测掩膜，做法与 `score_event` 完全相同：金标准是线时，金标准和预测（无论预测是框还是线）都按该图的线规则缓冲；金标准是面时，预测若是线，按评测默认的对角线 1% 缓冲（`score_polygon` 就是这样算的）。掩膜都在图像范围内，图外的预测部分不计入 |P|。
- **精确率** = |P∩G| / |P|，**召回率** = |P∩G| / |G|；线状题即正确度 / 完整度。无预测：召回率记 0，精确率不计（所以精确率的 n 等于有预测的题数）。本次没有出现"有预测但图内面积为 0"的题。**面积比** = |P| / |G|，报有预测题的中位数和 P > G 的占比。
- **统计**：bootstrap 百分位 95% CI，10 000 次，numpy `default_rng(0)`；距离和面积比给中位数的 CI，命中率、召回率、精确率给均值的 CI。难度三档：Kruskal-Wallis（带并列校正，χ² df = 2）和 Jonckheere-Terpstra（单侧"随档位变差"，置换 10 000 次），统计量与 `difficulty_cue_20261125/analyze.py` 相同（距离取负号，使"变差"方向一致）；中心距离分别报"只算有预测的题"和"无预测记为最远"两种。

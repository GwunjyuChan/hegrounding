# 最终 260 题评测结果：6 个模型变体（2026-11-26）

题目是最终 260 题（难度三档 133 / 51 / 76），其中 37 题原问法结尾是 “Mark the area / route / line…”，11-26 统一改为 “Mark the location.” 并让全部模型重跑。模型：gpt-6.2-sol、claude-opus-5-5、gemini-4-neon（thinking LOW）、Qwen3.8-27B 4bit（11-26 在 MacBook 上 260 题全部重跑）、Gemma 4 26B-A4B q4（严格 / 宽松解析）。提示词 grounding-v2-20261119，所有模型逐字相同；解析和评分脚本与此前完全相同。各模型的调用参数见 `model_run_settings_20261119.md` 的 “2026-11-26 补跑” 一节。

本文件取代 `center_area_metrics_20261125.md` 和 `difficulty_cue_results_20261125.md` 中的模型数字（那两份是旧问法、4 个模型变体，保留作记录）。

## 结论

1. **Gemini 4 Neon（LOW）最好，Sol 第二，Claude Opus 5.5 第三，三者明显领先两个本地模型。** 平均 IoU：Gemini 0.480 [0.449, 0.510]，Sol 0.449 [0.418, 0.483]，Claude 0.396 [0.366, 0.427]，Qwen 0.162 [0.135, 0.190]，Gemma 0.027（宽松 0.032）。配对检验（逐题 IoU 差，置换 10 000 次）：Gemini − Sol = +0.030 [0.003, 0.059]，p = 0.032；Sol − Claude = +0.053 [0.024, 0.083]，p < 0.001。Gemini 只比 Sol 好一点，区间下界接近 0。
2. **三个闭源模型都能找对地方，差别在区域画得准不准。** 中心落在 5% 对角线以内：Sol 95.0%、Gemini 94.2%、Claude 92.7%；中心距离中位数 Sol 0.69%、Gemini 0.64%、Claude 1.27%。Claude 的问题是框画得偏大：面状题召回率 0.669 高于 Sol（0.587），但精确率只有 0.475（Sol 0.632、Gemini 0.588）。Gemini 召回最高（面状 0.716），精确率与 Sol 接近。
3. **难度三档只在 Qwen 上清楚地单调变差。** Qwen IoU 0.204 → 0.136 → 0.107（KW p = 0.008，JT p = 0.002），中心距离中位数 2.4% → 3.7% → 5.9%（JT p < 0.001），只算面状题时 IoU 0.228 → 0.141 → 0.054（JT p = 0.0001）。三个闭源模型全部题型合在一起时三档没有显著差别（IoU KW p 0.50–0.85）；只算面状题时 Sol（0.449 → 0.367 → 0.374，JT p = 0.037）和 Gemini（0.496 → 0.391 → 0.437，JT p = 0.042）有下降趋势，Claude 没有。线状题各模型都没有随档位下降。
4. **去掉几何类型提示后分数下降，改题是必要的。** 37 道改问法的题上，Sol 的 IoU 从 0.519 降到 0.446，Claude 从 0.443 降到 0.408，Gemma 宽松从 0.051 降到 0.049。Sol 260 题 IoU 因此从 0.460 降到 0.449。
5. **格式：闭源模型基本都合规，Gemma 最差。** 无法解析：Sol 0、Claude 0、Gemini 0、Qwen 2、Gemma 严格 58（宽松 1）。Gemini 有 110 题、Gemma 122 题把 JSON 包在代码块里，按既定规则照常计分；Claude 1 题在 JSON 前加了说明文字，也照常计分。
6. **Qwen 换环境后不能逐字复现。** 同一权重、同样参数，换成 M4 Pro + mlx-vlm 0.8.0 后，223 道未改的题里只有 75 题回复与 11-19 逐字相同，但平均 IoU 几乎不变（0.158 对 0.159）。260 题 IoU 0.162（11-19 为 0.168），hit@0.5 0.119（0.138）。

## 局限

- **推理强度不完全一样**：Sol 和 Claude 用默认设置（平均思考约 180 / 250 token），Gemini 用 LOW 档（约 780 token，思考关不掉），Qwen 和 Gemma 不思考。默认档的 Gemini 每题思考约 8,200 token；在 99 道非随机题上，默认档 IoU 0.437，同 99 题 Sol 为 0.433。
- **图像分辨率不同**：Sol 用 detail high；Claude 由服务端缩到长边 2576 px（9 题因 5 MB 上限在本地先缩到同一尺寸）；Gemini 和 Gemma 每张图只用约 1,100 个图像 token；Qwen 按原分辨率。
- **Qwen 的运行环境与 11-19 不同**（MacBook M4 Pro、mlx-vlm 0.8.0），回复不能逐字复现（见结论 6）。
- **MF0005** 的问题直接给出 “about two miles north of Marengo”，过不了出题规则里的“删文本测试”；这次保留，没有改。
- Gemini 的费用按第三方报道的单价估算，未在 Google 官方价格页核实。
